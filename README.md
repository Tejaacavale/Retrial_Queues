# Retrial Queue Simulator

![Queue Diagram](retrial.png)

A discrete-event simulation of the **M/M/1 retrial queue**, with analysis and visualization in Python.

## What is a Retrial Queue?

In a standard queue, blocked customers wait passively. In a **retrial queue**, customers who find the server busy on arrival leave and re-attempt after a random delay — forming an "orbit" of retrying customers. This naturally models telephone networks, call centers, and communication systems where repeated connection attempts occur.

This project simulates the **M/M/1 retrial queue**:
- Customers arrive as a Poisson process at rate **λ**
- Service times are exponential at rate **μ**
- Blocked customers retry after an exponential delay at rate **ν** (per customer in orbit)
- Single server

See `report.pdf` for the full theoretical background, including M/M/K analysis.

## How to Run

### Step 1 — Compile and run the simulator

Requires a C++11 compiler (e.g., `g++`). Using Make:

```bash
cd code
make          # builds compute
make test     # builds and runs all 14 tests
./compute
```

Or manually:

```bash
g++ -std=c++11 -O2 -o compute compute.cpp
./compute
```

You will be prompted for four inputs:

| Prompt | Symbol | Example value |
|--------|--------|---------------|
| Number of jobs | n | `10000` |
| Job Arrival Rate | λ | `5.0` |
| Job Service Rate | μ | `1.0` |
| Re-trial Rate | ν | `7.0` |

> **Stability condition**: the system is stable when ρ = λ/μ < 1.

Three output files are written to the `code/` directory:

| File | Contents |
|------|----------|
| `file1.txt` | Per-job row: `scheduled_time  arrival_time  departure_time  retry_count` |
| `file2.txt` | Parameters + summary metrics (avg wait time, avg system time, idle fraction, mean N(t)) |
| `file3.txt` | Per-job blocking probability estimates |

### Step 2 (optional) — Use as a Python library

The simulator can be imported directly into Python scripts or notebooks via a pybind11 extension.

**Install dependencies and build:**

```bash
cd code
pip install pybind11 setuptools
make python          # or: python setup.py build_ext --inplace
```

**Usage:**

```python
import retrial_queue
import numpy as np

result = retrial_queue.simulate(
    n_jobs=10000,
    arrival_rate=1.0,   # λ
    service_rate=5.0,   # μ  (stable: λ/μ = 0.2 < 1)
    retrial_rate=3.0,   # ν
    seed=42,            # omit for a random seed
)

print(result.avg_sojourn_time)    # E[T]
print(result.mean_n)              # E[N]  — should ≈ λ · E[T] by Little's Law

arrivals   = np.array(result.arrival_times)
departures = np.array(result.departure_times)
retries    = np.array(result.retry_counts)

probs = retrial_queue.compute_blocking_probabilities(result.completed)
```

See `code/example.py` for a complete runnable example.

### Step 3 — Run the analysis notebook

Install Python dependencies:

```bash
pip install -r requirements.txt
```

Open and run all cells in `code/code.ipynb`. The notebook reads the output files from Step 1 and writes the following plots to `images/`:

| Plot | Description |

| `interarrival1.png` / `interarrival2.png` | Interarrival time analysis |
| `mean_sojourn_times.png` | Average time spent in system |
| `blocking_probability.png` | Blocking probability over time |
| `littles_law_verification.png` | Empirical verification of Little's Law |
| `frequency_plot_of_pings.png` | Distribution of retry counts per customer |
